# Homepage

Jekyll site. Content is added, never hand-listed:

| To add… | Create a file in… | Front matter |
|---|---|---|
| a publication | `_publications/` | title, coauthors, venue, volume, pages, year, doi, pdf, abstract |
| a working paper | `_workingpapers/` | title, coauthors, status, year, pdf, abstract |
| a course | `_teaching/` | title, role, institution, level, year |
| a talk | `_talks/` | title, venue, location, year, slides |

Contact details, affiliation and links: `_config.yml` (`author:`). Education, awards, interests: `_data/`.
Preview: `bundle install && bundle exec jekyll serve`.
